Login button stuck loading

smartphone Android, Pixel 7
info v2.1.0
schedule Today 14:30

Description

When attempting to log in with valid credentials, the login button displays a loading spinner indefinitely and the user is never transitioned to the dashboard.

zoom_in

Expected Behavior

After clicking login, the app should authenticate and navigate to the home dashboard within 1-2 seconds.

Actual Behavior

Loading spinner spins infinitely. Network logs show the auth request succeeds (200 OK), but the UI state is not updated.

auto_awesome

AI Reproduction Steps

  1. Launch the Android application.
  2. Navigate to the Login screen.
  3. Enter valid email and password credentials.
  4. Tap the "Login" button.
  5. Observe the button state.

AI Root Cause Analysis

The AuthContext is not correctly dispatching the LOGIN_SUCCESS action upon receiving the 200 response from the API, causing the UI component to remain in the isLoading=true state.

// Suspected missing dispatch:
if (response.status === 200) {
  // Missing: dispatch({ type: 'LOGIN_SUCCESS', payload: response.data });
  navigation.navigate('Dashboard');
}
